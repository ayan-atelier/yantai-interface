# 砚台 · 界面整理

**当前版本：0.3.0 试用版 · SillyTavern 1.16.0 及以上**

把不常用的按钮和设置收起来，让手机、电脑上的酒馆界面更容易使用。图标、文字与颜色跟随当前主题。

这是独立扩展，可以单独安装，也可以与「砚台 · 角色书架」、叙事记忆和人设库搭配；不接管存档同步，也不要求其他模块必须安装。

## 安装

在酒馆中打开 **扩展 → 安装扩展**，粘贴：

```text
https://github.com/ayan-atelier/yantai-interface
```

分支／标签留空即可。选择「只给我安装」；如果同一台酒馆服务器的其他账号也需要使用，管理员可以选择「给所有人安装」。安装后刷新酒馆。

**入口：输入栏左侧三横菜单 → 界面整理。** 扩展设置页也有「砚台 · 界面整理」折叠栏。

如果你之前安装的是文件夹版：先停用旧的界面整理，备份并把旧 `yantai-interface` 文件夹移出扩展目录，再用上面的链接安装，避免两份同时加载。设置保存在当前酒馆账号中，换成链接安装仍沿用同一个设置位置。

如果原来的完整砚台仍在运行，请先关闭其中的界面调整，或停用完整砚台，避免重复调整同一处界面。

## 可以整理哪些位置？

| 位置 | 功能 |
| --- | --- |
| 顶部按钮 | 逐项显示或隐藏；全部隐藏时收起空栏，重新显示任意按钮即可恢复。 |
| 三横菜单 | 把不常用工具收进「更多工具」，需要时展开。 |
| 魔法棒 | 识别常见原生与第三方入口，逐项隐藏或恢复。 |
| 扩展页 | 统一为一列，把低频设置和旧 Extras API 连接区收进顶部的「更多扩展设置」。 |
| 预设页 | 折叠生成参数与高级设置，保留提示词列表。 |
| 用户设置 | 按主题、角色卡、聊天等用途分组折叠，原生搜索时暂时展开。 |

在手机端或 TauriTavern 中，扩展页会限制在当前屏幕宽度内；正则工具栏的操作项会自动换行，避免页面被桌面布局撑宽。不同主题如果仍出现横向滚动，请反馈酒馆版本、设备、主题和触发步骤。

扩展页按「更多扩展设置 → 系统工具 → 酒馆助手 → 砚台 → 其他插件」组织。其他第三方插件按首次识别顺序记住，新增项接在后面；这不代表实际安装日期。

设置页提供搜索、位置说明和「重新识别入口」。各账号分别保存自己的选择。

**隐藏入口不会停用对应插件。** 如果要关闭插件本身，请到酒馆的扩展管理中操作。界面整理不改变预设参数、API 地址或聊天内容。

## 更新与恢复

- 通过链接安装后，在酒馆的扩展管理中检查更新，找到「砚台 · 界面整理」并点击更新，完成后刷新酒馆。
- 本插件不静默自动更新；这一版使用酒馆原生的更新入口，没有另做插件内的更新与回退面板。
- 想撤销界面调整，点三横菜单中的「界面整理 → 恢复原界面」，扩展页也有同名按钮。之后可重新开启并设置。

## 兼容与反馈

- 顶部空栏收起已与「砚台 · 角色书架 1.4.4」的尺寸测量逻辑配合；底部浮动输入栏的避让仍由书架处理。
- 无法识别的特殊主题结构会保持原样。后装扩展通常能被自动识别；必要时先打开对应菜单，再点「重新识别入口」。
- 已完成本地回归和原生页面结构验证；第三方主题和不同移动端环境仍需要实测，不能保证每一种改写布局都适用。

反馈时请附上 **酒馆版本、设备／浏览器、主题名称、截图和触发步骤**，也请说明是链接安装还是旧文件夹版。
